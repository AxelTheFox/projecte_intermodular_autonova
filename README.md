
# COCHES10

Aplicació web d'un concessionari de vehicles de segona mà.

## Descripció

COCHES10 és una plataforma web que permet consultar
vehicles disponibles, buscar cotxes mitjançant filtres
i enviar sol·licituds per vendre vehicles al concessionari.

## Tecnologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB

## Estat del projecte

En desenvolupament.
